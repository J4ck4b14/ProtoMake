# ProtoMake 0.16.0 release notes

ProtoMake 0.16.0 introduces Interchange IR v1, centralized target coordinate profiles, stable export identity maps, capability metadata, deterministic per-target reports, and an editor portability-analysis workflow. It also completes public-facing versioning, browser support, roadmap, showcase, issue-reporting, and release documentation.

This release does not yet claim that a target engine project has been generated. Godot, Unity, and Unreal tooling land as separately verified 0.16.x checkpoints. ProtoMake TypeScript remains unrestricted and is reported as manual target work; portable Behaviour Graph support is explicit by node type.

Existing project schema v10 data migrates to project schema v11 by updating engine metadata. Scene schema remains v1. Interchange has its own version 1 contract.
