# ProtoMake 0.16.3 release notes

ProtoMake 0.16.3 completes the initial portability series with deterministic Unreal Engine 5.4+ project export. The ZIP contains a normal `.uproject`, ProtoMake source media and Interchange data, plus a two-module C++ plugin: an Editor importer and a gameplay Runtime module.

The Editor importer uses AssetTools, Unreal world/actor/component APIs, Paper2D assets and Enhanced Input assets to reconstruct the supported project subset under `/Game/Generated/ProtoMake`. Stable ProtoMake GUIDs and the full source component JSON remain attached through `UProtoMakeIdentityComponent`. Sprite clips become PaperFlipbooks, scene hierarchies become attached actors, and supported Graph Behaviours use `UProtoMakeGraphComponent` at runtime.

ProtoMake emits no `.uasset` or `.umap` binaries and does not use Unreal Python for gameplay. Unreal creates and owns target binary assets. The source IR, manifest and complete portability report remain outside binary Content assets for review and deterministic reimport.

UI/UMG, Niagara, 2D lighting, prefab authoring assets, exact animation state logic, complete Enhanced Input modifier parity, arbitrary TypeScript, and platform services remain explicitly reported for manual target-side work. ProtoMake remains canonical and no round trip is claimed.
