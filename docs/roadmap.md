# Roadmap

## Delivered

ProtoMake 0.10–0.15 established fast scripting/visual logic, runtime UI and persistence, 2D authoring, live iteration, and game-feel systems. ProtoMake 0.16 establishes the public-release and Interchange foundation. ProtoMake 0.16.1–0.16.3 deliver deterministic Godot 4, Unity and Unreal Engine 5 one-way exporters.

## Portability series

1. ProtoMake 0.16.1 — deterministic Godot project generation. **Delivered.**
2. ProtoMake 0.16.2 — Unity package/project output with a supported Editor importer. **Delivered.**
3. ProtoMake 0.16.3 — Unreal Engine 5 import bundle and Editor plugin; no synthesized `.uasset` files. **Delivered.**

Future work is evidence-led: profile larger projects, validate generated outputs in installed target engines, expand only graph nodes with tested translators, and improve browser/device coverage. Round-trip target-engine editing, general TypeScript translation, and lossless export claims are explicitly outside the current roadmap.
